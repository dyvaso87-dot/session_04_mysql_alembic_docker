Problema version mas actual de python.

Usar una version anterior de python:

1. Crea el entorno virtual con Python 3.11:

```powershell
py -3.11 -m venv venv
```

2. Actívalo:

```powershell
.\venv\Scripts\Activate.ps1
```

3. Verifica que realmente quedó con Python 3.11:

```powershell
python --version
```

Debe salir algo como:

```text
Python 3.11.x
```

4. Actualiza `pip`:

```powershell
python -m pip install --upgrade pip
```

5. Instala FastAPI:

```powershell
python -m pip install "fastapi[standard]"
```

6. Verifica FastAPI y Uvicorn:

```powershell
python -m pip show fastapi
python -m pip show uvicorn
```

7. Levanta tu API:

```powershell
python -m uvicorn main:app
```

8. Prueba en el navegador:

```text
http://127.0.0.1:8000
```

y la documentación:

```text
http://127.0.0.1:8000/docs
```

Si eso funciona, ya puedes intentar:

```powershell
python -m uvicorn main:app --reload
```
